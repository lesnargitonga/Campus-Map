# UML Diagrams (Lean Set)

Goal: Present a professional yet space-efficient architecture view set. Each diagram is intentionally pruned to only the core domain + feature extensions (Accessibility & Hazards) just implemented.

Diagrams included:
1. Context Diagram
2. Core Use Cases
3. Domain (Class) Model
4. Component Diagram
5. Route Computation Sequence
6. Deployment (Minimal)

Render instructions: Use any PlantUML renderer (online server or VSCode extension). All `.puml` files are self-contained (no includes) to minimize friction.
